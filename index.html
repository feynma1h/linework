Colophon

Each artwork here is a single JavaScript function: it receives a canvas and a handful of parameters, and traces curves with plain trigonometry and noise. The moving pieces are fragment shaders — tiny programs your graphics card runs for every pixel, sixty times a second. There is no framework and no build step; the whole thing is plain ES modules a browser runs as-is.

Posting a new piece means writing one function and adding one entry to a list. The sliders, plotting animation, lightbox, permalinks and exports all come for free. That's the entire publishing workflow: keyboard in, art out. The README in the repo walks you through it.

Every plotted piece (and your Studio creations) exports as SVG — real vector paths, not pixels. Feed that file to an AxiDraw or any pen plotter and these drawings become physical ink on physical paper, exactly the way string artists and spirograph makers work by hand. The background sits on its own layer so you can delete it before plotting.

Fork it, change the code in src/, and switch on GitHub Pages — your own gallery gets a public URL in about two minutes. Every slider position is shareable; the link encodes the math itself.

// adding a new artwork = one object in src/art/collection.js

  params: [
    { key:"r", label:"inner gear", min:20, max:95 },
    { key:"d", label:"pen offset", min:10, max:90 },
  ],
  *draw(ctx, w, h, p, rng) {
    // your equation goes here;
    // `yield` now and then → it plots itself live,
    // and the same code becomes your SVG for the plotter
  }
}
